# METGO — App móvil (React Native)

Ubicación canónica tras unificación del layout v4 (`frontend/app_movil/`).

## Antes

`frontend/dashboards/app_movil_metgo/` (obsoleto; ver stub en esa ruta).

## Desarrollo

```bash
cd frontend/app_movil
npm install
npm start
```

Configure la URL de la API en `src/services/ApiService.js` (puerto **8080** en desarrollo).
